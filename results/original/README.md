# Original capstone artifacts

These images preserve the figures published in the [original poster](../../Poster/%E8%B3%87%E8%A8%8A115%E5%B0%88%E9%A1%8C%E6%B5%B7%E5%A0%B1.pdf). They are not generated by the revised experiment pipeline.

| File | Source |
| --- | --- |
| `cpi.png` | Original poster Figure 4, embedded image 007 |
| `reward.png` | Original poster Figure 5, embedded image 006 |
| `demo-reward.png` | Original repository `statics/images/sac_reward.png`, a separate demo example |

Poster images were extracted directly without redrawing, smoothing, or reconstructing data:

```bash
pdfimages -png Poster/資訊115專題海報.pdf /tmp/poster-image
# image-006.png -> reward.png; image-007.png -> cpi.png
```

The poster qualitatively reports SAC reaching a lower shop-price-index range and better reward than the two displayed baselines. Original raw logs, exact seeds/configurations, and baseline implementations are not included in the released demo. These figures do not establish statistical significance or a measured live-server benefit. Newly executed experiments belong in a separately labeled result directory.
